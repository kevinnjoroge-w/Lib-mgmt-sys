# User Guide - St. Bakhita Library Management System

Welcome to the St. Bakhita Library Management System. This guide provides instructions on how to use the various features of the system based on your assigned role.

## Getting Started

To access the system, navigate to the application URL in your web browser. You will be prompted to log in or register a new account.

### Registration and Login
- **Register**: If you are a new user, click the Register link. Provide your name, email, and choose a secure password. By default, new accounts are assigned the Student role.
- **Login**: If you already have an account, enter your email and password to access your dashboard.

---

## Student Features

As a student, you can browse available books and manage your borrowing activity.

### Finding Books
- Navigate to the Browse Books page.
- Use the search bar to find books by title, author, or ISBN.
- Filter by genre or category to narrow down your search.

### Borrowing and Returning
- **Borrow**: If a book is available, click the Borrow button. You can choose a custom return duration (default is 14 days).
- **Renew**: If you need more time with a book, you can renew it from your borrow history. This extends the due date by 7 days.
- **Return**: When you are finished with a book, click the Return button in your history.

### Fines and History
- **My Books**: View a list of books you currently have or have borrowed in the past.
- **Fines**: If a book is returned past its due date, a fine may be issued. You can view any outstanding fines on the Fines page.

---

## Librarian Features

Librarians have additional permissions to manage the library's physical inventory and process user transactions.

### Managing the Catalog
- **Add Book**: Use the Add Book form to include new items in the library catalog. You will need to provide details like title, author, ISBN, and category.
- **Edit/Delete**: You can update book information or remove books from the catalog if they are no longer available.

### Processing Returns and Fines
- **Returns**: Librarians can process returns for any student to ensure the system reflects the physical status of the library.
- **Fine Management**: When a student pays their fine at the library counter, a librarian can mark the fine as Paid in the system.

### Dashboard Statistics
- Access the dashboard to see high-level statistics, including the total number of books, active borrows, and total fines across the system.

---

## Administrator Features

Administrators have full control over the system, including user management and global settings.

### User Management
- **View Users**: Access a list of all registered users in the system.
- **Update Roles**: Change a user's role between Student, Librarian, and Admin.
- **Delete Users**: Remove user accounts from the system.

### System Settings
- **Fine Rates**: Configure the daily fine rate for overdue books. This rate is used globally to calculate new fines.

### Administrative Oversight
- Admins can perform any action available to Students and Librarians, providing full oversight of the system's operations.
